# Better-Saving
Reliable manual, autosave and backups for Geometry Dash.

<img src="logo.png" width="150" alt="Better Saving logo" />

## Features
- Manual save and Autosave on a timer
- Save when completing a level
- Android exit button that saves before closing
- Rolling backups and one tab restore
- More

## Installation
1. Download the `.geode` file from [Releases](./releases).
2. Just Import it into the game using geode.
3. Launch Geometry Dash — Better Saving runs automatically.
